# onurdenizakan.com

Personal academic website for **Onur Deniz Akan** — post-doctoral researcher in earthquake engineering.

Built with pure HTML5 + CSS3. No JavaScript frameworks, no build tools.

## Live site

[www.onurdenizakan.com](https://www.onurdenizakan.com)

## Structure

| Page | Path |
|------|------|
| Home | `index.html` |
| About | `about/main.html` |
| Research | `research/main.html` |
| Courses | `courses/main.html` |
| OpenSees Dev | `opensees/main.html` |

## Deployment

- **`main`** — development branch
- **`publish`** — production branch (GitHub Pages serves from here)
